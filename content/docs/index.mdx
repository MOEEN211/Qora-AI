## A small, useful starting point

The template exposes two workspace operations through both interfaces. Each connection has explicit permissions and access to one workspace.

| Operation                                       | What you can do                              | Permission |
| ----------------------------------------------- | -------------------------------------------- | ---------- |
| [Get workspace](/docs/api/workspaces/get)       | Read its name, identifier, and creation date | Read       |
| [Rename workspace](/docs/api/workspaces/rename) | Update its display name                      | Read/write |
