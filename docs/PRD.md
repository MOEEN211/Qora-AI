# Starter behavior and customization map

The starter is a foundation for the buyer’s own SaaS. The delivered source includes working features with provider prerequisites; it does not include a seller-operated backend or promise that your new installation has already passed live acceptance.

| Feature | Contract and guide |
| --- | --- |
| Setup | Three credentials, read-only preflight, hosted project creation and retry-safe install: [KICKSTART.md](KICKSTART.md) |
| Authentication | Password, recovery, optional verification, magic link and separately configured Google: [AUTHENTICATION.md](AUTHENTICATION.md) |
| Onboarding | Three skippable account-scoped steps, saved progress: [ONBOARDING.md](ONBOARDING.md) |
| Workspaces | Automatic signup workspace, invited-only signup, owner/admin/member roles, switching, invitations, ownership transfer and deletion guards: [WORKSPACES.md](WORKSPACES.md) |
| Settings | Profile/avatar, preferences, API keys and guarded deletion: [SETTINGS.md](SETTINGS.md) |
| Billing | Separate subscription per workspace; Starter/Pro/Growth monthly/yearly seed; no seat caps or AI allowance renewal: [BILLING.md](BILLING.md) |
| Optional AI | Saved streaming chats, 100 one-time credits per workspace and documented removal: [AI.md](AI.md) |
| Integrations | Workspace read/rename REST and scoped MCP OAuth: [API-MCP-PLAN.md](API-MCP-PLAN.md) |
| Operator admin | Normal login, current operator membership, read-only customers, equal operators managing membership: [ADMIN.md](ADMIN.md) |
| Notifications and feedback | Private account inbox/preferences, private bug reports and shared feature board: [NOTIFICATIONS.md](NOTIFICATIONS.md), [FEEDBACK.md](FEEDBACK.md) |
| Public product website | Customizable landing/pricing/contact, blog, sample legal pages and product docs: [MARKETING.md](MARKETING.md), [BLOG.md](BLOG.md), [SEO.md](SEO.md) |
| Deployment | Buyer-owned GitHub/Vercel resources, runtime allowlist, shared hosted origin: [DEPLOYMENT.md](DEPLOYMENT.md) |

Customize the app name, product copy, feature entitlements, pricing and legal pages for your business. Payment for the source license is distinct from the workspace subscription prices displayed in the sample app. No template-purchase or buyer-invitation automation is included in this application.

General file management, analytics integrations, internationalization and automatic upstream updates are not included capabilities. Do not create misleading placeholders for them. Use [PLAN.md](PLAN.md) to record actual acceptance for your installation before promising a capability to customers.
