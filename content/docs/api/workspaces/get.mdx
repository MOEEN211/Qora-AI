---
title: Get workspace
description: Read the connected workspace's name, UUID, readable identifier, and creation date.
---

<Endpoint method="GET" path="/api/v1/workspace" />

## Request

This endpoint accepts no query parameters or body. The API key selects the workspace.

<Tabs items={["curl", "TypeScript"]} groupId="docs-request-language" persist>
<Tab value="curl">

```bash title="Terminal"
curl https://your-app.example/api/v1/workspace \
  -H "Authorization: Bearer $WORKSPACE_API_KEY"
```

</Tab>
<Tab value="TypeScript">

```ts title="get-workspace.ts"
const response = await fetch("https://your-app.example/api/v1/workspace", {
  headers: { Authorization: `Bearer ${process.env.WORKSPACE_API_KEY}` },
});
const result = await response.json();
if (!response.ok) throw new Error(result.error);
console.log(result.data);
```

</Tab>
</Tabs>

## Response

```json title="200 OK"
{
  "data": {
    "id": "4fd7c62d-66c5-41d3-bc28-6b5ec0c17322",
    "name": "Acme Studio",
    "slug": "WRK7M2Q9A4X1B",
    "created_at": "2026-01-15T10:30:00+00:00"
  }
}
```

| Field        | Meaning                                                    |
| ------------ | ---------------------------------------------------------- |
| `id`         | Internal workspace UUID                                    |
| `name`       | Editable display name                                      |
| `slug`       | Permanent readable identifier; renaming does not change it |
| `created_at` | Creation timestamp in ISO format                           |

## MCP equivalent

Call [`get_workspace`](/docs/mcp/tools#get_workspace) with an empty object. The tool returns the workspace object directly as structured content, without the REST `data` envelope.
